# 桌面收纳盒 · DesktopDock

一个常驻桌面的左侧抽屉：**鼠标贴到屏幕最左边就滑出**，把桌面上的快捷方式收进一个窗口，
同时提供一块**可自由调整字体与大小**的时钟 / 天气面板（三档信息层级 LOD）。

原生 WPF（.NET 10），单文件启动、无外部依赖、无需联网即可打开（天气联网时才有数据）。

## 快速开始

| 操作 | 说明 |
| --- | --- |
| 双击 `启动.bat` | 启动（优先启动已安装副本，没有再启动 `dist\DesktopDock.exe`） |
| 鼠标贴到屏幕最左边 | 抽屉滑出（默认贴边 4px 内、约 80ms 后触发） |
| 鼠标移开 | 0.7 秒后自动收起（可在设置里改） |
| 托盘图标 | 左键：展开/收起；右键：菜单（显示桌面图标、开机自启、退出等） |
| `Esc` | 先关设置页，再收起面板 |

> 第一次启动会**自动安装到 `%LOCALAPPDATA%\Programs\DesktopDock`** 并从那里重启
> （原来的下载目录只当作"安装包"，之后删掉也不影响）。原因见下面「权限与开机自启」。

## 权限与开机自启

这是这个版本重点修掉的问题：程序以前会以「低权限模式」运行，托盘、开机自启、隐藏桌面图标、
用资源管理器打开文件夹全部失效。

### 真正的原因

不是杀毒软件。Windows 有一套**强制完整性控制（MIC）**：进程的完整性级别会被**可执行文件的
完整性标签**拉低。如果 exe 所在目录被打过 `Mandatory Label\Low Mandatory Level`（常见于
从下载目录直接运行、或目录被某些沙箱/解压工具写过 ACL），那么不管你是双击、放启动文件夹、
还是用计划任务、甚至 UAC 提权，进程都会被钉在 **Low IL**：

- 写 `HKCU\...\Run` → `Requested registry access is not allowed`
- 写启动文件夹 → `Access is denied`
- 给 explorer 的 `SysListView32` 发消息（隐藏桌面图标）→ 被 UIPI 拦掉
- `ShellExecute` 打开文件夹 → 被拒

### 现在的做法

| 机制 | 说明 |
| --- | --- |
| 自我安装 | 启动时如果发现自己不在 `%LOCALAPPDATA%\Programs\DesktopDock`，就把 exe/依赖复制过去、清一次完整性标签、从新位置重启（`--portable` 可关闭） |
| 低权限自愈 | 已经在本机目录却仍是 Low：清标签，再借计划任务或 `explorer.exe` 重新拉起（`Low → Low` 直接 `Process.Start` 是没用的，子进程还是 Low） |
| 单一自启通道 | 以前 `HKCU Run`、启动文件夹 `.cmd`、计划任务三条同时存在，登录时两个实例抢单实例锁，**抢赢的往往恰好是低权限那个**。现在任意时刻只保留一条 |
| 计划任务更稳 | 用 XML 注册：`DisallowStartIfOnBatteries=false`（电池上也能起）、`StopIfGoingOnBatteries=false`（拔电不会被杀）、`ExecutionTimeLimit=PT0S`（不再 72 小时后被结束）、登录延迟 10 秒等桌面就绪 |
| 任务自修复 | 程序被计划任务拉起时本身带管理员令牌，发现任务还指向旧副本会**就地改写任务**，不用再弹 UAC |
| 诊断日志 | 每次启动记录 `integrity`、`launcher parent=名字(pid, 完整性级别)`、`location`（含 exe 的标签），出问题一眼能看出是谁用什么权限拉起来的 |

设置页 →「权限与启动 / 开机自启」里可以直接：

- **安装到本机并重启**（推荐，彻底解决目录标签问题）
- **只清除 Low 标签并重启**（原地修复）
- **修复自启**（清掉旧计划任务 / 重复通道，只留一条，需要一次 UAC）
- **改用计划任务（最高权限）**（登录后静默以最高可用权限启动，不弹 UAC）

如果程序已经起不来（标签坏得比较彻底），双击目录里的 **`修复权限.bat`**：
它由 `cmd.exe`（系统 Medium 进程）执行 `icacls /setintegritylevel Medium`，绕过"Low 改不了 High"的死结。

## 功能

### 1. 左边缘呼出

- 屏幕左边缘是一条 **7px 的发光提示条**（可关闭），鼠标可直接穿透，只作视觉提示。
- 贴边停留约 80ms 即展开，鼠标离开面板后按延迟自动收起。
- **仅在桌面生效**（默认开启）：只有前台窗口是桌面（`Progman` / `WorkerW` / `SHELLDLL_DefView`）时才响应贴边；
  在 Blender、浏览器等软件里工作时不会弹出，左侧提示条也会自动隐藏。可在设置里关掉这条限制。
- **动画走 GPU 合成**：面板本身用 `TranslateTransform` 滑入滑出，窗口位置固定不动，
  不再逐帧 `SetWindowPos`，所以刷新率多高就跟多高——144Hz 屏上也是逐帧顺滑，不会跳帧。
- **不给 DWM 画窗框**：Win11 默认会给窗口加圆角裁剪 + 1px 边框，这两个装饰钉在**窗口矩形**上，
  而面板是在窗口内部滑动的，滑入滑出时就会看到一条"不同步的白边"。现在用
  `DWMWA_WINDOW_CORNER_PREFERENCE = DONOTROUND` + `DWMWA_BORDER_COLOR = NONE` 关掉，
  面板形状完全由 WPF 自己绘制。
- 多显示器：在**鼠标所在那块屏**的左边缘触发。
- 面板垂直居中，高度自适应屏幕工作区。
- 收起时面板整块平移到窗口左侧之外（不做 `Collapsed`，否则最后一帧来不及提交会留下一条残影），
  此时窗口整块透明，实测点击会穿透到桌面（`WindowFromPoint` 命中 `SysListView32`）。

### 1.5 毛玻璃

- 展开瞬间抓一张面板背后的桌面 → 缩到 5.5% → 两轮盒式模糊 → 轻微去饱和 → 交给 GPU 双线性放大。
  观感接近系统 Acrylic，但每帧零成本（不像实时 `BlurEffect` 那样吃显存和帧时间）。
- 上面盖一层暗色渐变蒙层，浓度由「蒙层浓度」滑块控制（**0 = 完全透明**，只剩毛玻璃；0.45 很透，1.0 接近不透明）。
- 设置里可一键关掉毛玻璃，退回纯渐变背景。

**透明效果（真透明）**

- 勾上「透明效果」后不再截屏，面板不画任何底色，**背后的窗口、动态壁纸实时透出来**，
  只用「蒙层浓度」压暗；开启时忽略毛玻璃。
- 和毛玻璃的区别：毛玻璃是一张**模糊的快照**（打开瞬间拍的，之后不动），透明效果是**实时的**（背后的窗口滚动、视频播放都能看见）。
- 试过 DWM 的亚克力（`ACCENT_ENABLE_ACRYLICBLURBEHIND`）实时模糊，但它和
  `AllowsTransparency` 的 layered 窗口不兼容（整块渲染成黑色），所以这里给的是真透明而不是实时模糊。

### 2. 收纳桌面快捷方式

- 自动扫描：**用户桌面 + 公共桌面**。
- 收录内容：文件夹、`.lnk`、`.url`、`.appref-ms`、`.exe`、`.bat`、`.cmd`、`.ps1`、`.msc`。
- 图标取自系统外壳（`IShellItemImageFactory`），带透明通道，清晰不糊。
  提取放在**一条专用 STA 线程上串行执行**——Shell 图标扩展在并发 MTA 调用下会偶发返回空图标或张冠李戴。
- 单击磁贴启动。**文件夹**先尝试用资源管理器打开；若 800ms 内没有出现对应的资源管理器窗口
  （部分机器/受限环境下对目录做 `ShellExecute` 会直接返回「拒绝访问」），自动切换为**内置文件浏览**：
  面包屑路径、返回上级、子文件夹可继续进入、文件点击即开，底部还有「用资源管理器打开」可再试一次。
- 顶部搜索框即时过滤；扫描结果按「文件夹优先 + 名称」排序。
- 桌面增删文件会通过 `FileSystemWatcher` 自动刷新（约 0.7s 防抖），也可点刷新按钮强制重扫。
- 可选「隐藏桌面图标」：把桌面图标收起来，只剩这个收纳盒；**退出程序时自动恢复**，不会把你的桌面变空。

### 3. 时钟 + 天气（可自定义）

- 时钟：时/分 + 秒（可关）、日期、星期、城市。
- 天气：当前温度、天气描述、体感、湿度、风速，以及 5 天预报（高/低温、天气符号）。
- 数据源 **Open-Meteo**（免费、无需 API Key），按城市名地理编码，默认上海。
- 断网时显示上一次缓存，并在提示里说明。

**信息层级 LOD（3 档）**

| 档位 | 显示内容 |
| --- | --- |
| 简洁 | 时间 + 温度 |
| 标准 | + 秒、日期、城市、天气描述、体感 / 湿度 / 风 |
| 丰富 | + 5 天预报 |

**可调项**（设置里全部即时生效）

- 字体（任意已安装字体，带字体预览）
- 时钟字号、天气字号、快捷方式名称字号、图标尺寸
- 面板宽度、蒙层浓度（0 ~ 1，0 为完全透明）、毛玻璃开关、透明效果（真透明）
- 左边缘触发宽度、自动收起延迟、仅在桌面生效
- 显示秒 / 24 小时制 / 显示天气 / 显示边缘提示条
- 天气城市（支持「杭州」「Tokyo」这类中英文）、摄氏 / 华氏
- 隐藏桌面图标、开机自动启动
- 壁纸时间 / 壁纸信息条的开关、字体、字号、位置

### 4. 壁纸时间（右上角，无底板）

- 一块直接压在壁纸上的大时间：**没有卡片、没有底色**，只有字和一层柔光。
- 贴在**桌面之上、普通窗口之下**：看桌面时它在，打开软件就被盖住；鼠标点击直接穿透。
- **字色跟着壁纸走**：启动时（以及每 60 秒、且桌面在前台时）采样右上角区域的平均亮度，
  亮壁纸用墨色字 + 淡白光晕，暗壁纸用白字 + 暗光晕，换壁纸也不用改设置。
- 显示层级三档，字体、字号都能单独调：

| 档位 | 显示内容 |
| --- | --- |
| 简洁 | 时间（+ 秒，跟随「显示秒」） |
| 标准 | + 日期 |
| 丰富 | + 星期 |

字号范围 **18 ~ 140 pt**（默认 80），日期/星期按比例跟着放大；字体默认跟随主界面字体，
也可以单独指定。

**位置调节**

- **直接拖**：设置 → 壁纸时间 →「拖动定位」，时间会临时取消鼠标穿透，按住拖到任意位置，
  松手即保存（30 秒不拖自动退出）。拖完会按新位置重新采样壁纸亮度。
- **精确调**：`距右边` / `距顶部` 两个滑块（相对工作区右上角，单位 DIP），即时生效。
- **回到右上角**：一键恢复默认边距（52 / 52）。

### 5. 壁纸信息条（左下角）

和壁纸时间一样贴在桌面上（位于窗口之下、按壁纸明暗自动配色），一排两组信息：

- **性能**：`CPU 24% ─── RAM 49% ─── GPU 42%`，细线 + 百分比，每秒刷新。
  - CPU 用 `GetSystemTimes` 前后差值；RAM 用 `GlobalMemoryStatusEx`；
  - GPU 读性能计数器 `GPU Engine / Utilization Percentage`，把所有引擎加起来并封顶 100。
- **正在播放**：封面缩略图、标题、歌手、进度条、`0:19 / 6:06`、正在播放 / 已暂停。
  - 走系统 **GSMTC**（GlobalSystemMediaTransportControls），浏览器、Spotify、网易云等
    支持系统媒体控制的播放器都能识别；播放状态/进度每秒刷新，换歌/换封面由事件驱动。
  - 没有在放的歌时，音乐块自动收起，只剩性能。
- **控制**：`⏮ ⏯ ⏭` 三个小按钮，调用 GSMTC 的 `TryTogglePlayPause` / `TrySkipPrevious` / `TrySkipNext`，
  播放中图标自动变成暂停。
  - 按钮底色调成 alpha=12 的极淡黑：**分层窗口对全透明像素是穿透的**，背景如果全透明，
    只有字形那几颗像素点得中，几乎没法按。
  - 因此信息条不再整块鼠标穿透——空白像素仍然穿透，只有文字/按钮这些不透明像素会接住点击。
- **进度**：进度条可以直接点、可以直接拖。
  - 本地播放：`MediaPlayer.Position` 精确跳转；系统会话：`TryChangePlaybackPositionAsync`（由播放器决定支持程度）。
- **播放列表**：点 `☰` 打开，毛玻璃背景、字体跟随设置里的界面字体。
  - 扫描「音乐文件夹」（默认系统「我的音乐」，含子目录、去重上限 3000 首），列表点一行就播；
    `ListBox` 虚拟化，上千首也不卡。
  - 点行播放用的是**坐标命中**（`InputHitTest` 找到 `ListBoxItem` 再播），
    不依赖 `ListBox.SelectionChanged`——实测点在行内文字上时选中事件不触发，会表现为"点了没反应"。
  - 播放的是本地文件时，信息条优先显示本地曲目（能精确 seek），没有本地曲目时才显示系统会话。
  - 系统缺解码器时不会静默失败：信息条显示「无法播放（格式不支持）」，日志里有具体错误码。

设置里可以分别关掉「CPU / RAM / GPU」和「正在播放的音乐」，整个信息条有总开关；
「整体大小」滑块（60% ~ 220%）会连字号、封面、细线长度、间距一起等比缩放。
位置固定在左下角（距左边/底边 52 DIP）。
音乐文件夹可以在设置里改（`选择音乐文件夹…`），播放列表每次打开会重新扫描。

## 构建

```powershell
# 开发构建
dotnet build DesktopDock.csproj -c Release

# 发布到 dist/
dotnet publish DesktopDock.csproj -c Release -r win-x64 --self-contained false -o dist
```

运行环境：Windows 10/11 + .NET 10 Desktop Runtime（本机已安装）。

调试用启动参数：

```powershell
DesktopDock.exe --open        # 启动后立刻展开面板
DesktopDock.exe --settings    # 展开并停在设置页
DesktopDock.exe --no-hover    # 关闭悬停逻辑（配合上面两个做自动化截图）
DesktopDock.exe --portable    # 不安装到 %LOCALAPPDATA%，就在原地跑（开发调试用）
DesktopDock.exe --takeover    # 接管已在运行的实例（迁移/重启时内部使用）
DesktopDock.exe --move-widget # 启动后直接进入壁纸时间的拖动模式（调试用）
```

自启相关的内部参数（由程序自己用 UAC 拉起，不需要手动执行）：
`--install-autostart` 创建计划任务，`--repair-autostart` 清理重复自启通道。

## 已知限制

- 天气需要联网；接口被墙/断网时只显示缓存。
- 只收纳桌面**第一层**内容（不递归子文件夹）。
- 隐藏桌面图标依赖资源管理器的 `SysListView32`，个别系统主题下可能无效（设置里会静默失败，不影响其它功能）。
- 如果某个目录被外部工具反复写入 Low 完整性标签，装在本机目录的副本不受影响；但如果你坚持从那个目录
  直接运行，仍会被降权——这时用 `修复权限.bat` 或设置页里的「清除 Low 标签并重启」。
- 计划任务模式需要一次 UAC 授权；不想授权就用默认的 `HKCU Run`（普通权限，功能一样完整）。
- 以管理员身份运行时，打开文件夹会以管理员身份打开资源管理器——这是 Windows 的行为，不是本程序的。
- 左下角「GPU」依赖性能计数器 `GPU Engine`（Win10 1709+ 才有），个别驱动/虚拟机上可能读不到，会显示 0%。
- 「正在播放」依赖系统媒体控制（GSMTC）：播放器需要支持它（Edge、Spotify、网易云、Groove 等都可以）；
  纯本地播放器若没接入系统媒体控制，则读不到曲目。
